# automation-framework

Small test automation project I made during my tester course (Selenium + Java).

What's inside:
- Page Object pattern (home, sign in, shop, cart and checkout pages)
- driver setup for Chrome and Firefox
- settings in `framework.properties`
- TestNG

It's a training project and it's not finished. Only the first test (sign in) is started.

To run it, put your test account email and password in `src/main/resources/framework.properties` and run `mvn test`.
